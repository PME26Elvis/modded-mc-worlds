| Field | Value |
|---|---|
| Folder | `project-arc-light-the-hanging-pavilion` |
| Minecraft version | `1.20.1` |
| Pack version | `1.2.6` |
| Launcher | `CurseForge` |
| Main world folder | `worlds/main` |
| Extras folder | `extras` |

## Where to put the world

Put the world save contents under:

```text
packs/project-arc-light-the-hanging-pavilion/worlds/main/
```

Best layout:

```text
packs/project-arc-light-the-hanging-pavilion/worlds/main/level.dat
packs/project-arc-light-the-hanging-pavilion/worlds/main/region/
packs/project-arc-light-the-hanging-pavilion/worlds/main/playerdata/
```

Also accepted by the packaging tool:

```text
packs/project-arc-light-the-hanging-pavilion/worlds/main/New World/level.dat
```
