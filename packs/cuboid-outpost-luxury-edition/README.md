| Field | Value |

| Main world folder | `worlds/main` |
| Extras folder | `extras` |

## Where to put the world

Put the world save contents under:

```text
packs/cuboid-outpost-luxury-edition/worlds/main/
```

Best layout:

```text
packs/cuboid-outpost-luxury-edition/worlds/main/level.dat
packs/cuboid-outpost-luxury-edition/worlds/main/region/
packs/cuboid-outpost-luxury-edition/worlds/main/playerdata/
```

Also accepted by the packaging tool:

```text
packs/cuboid-outpost-luxury-edition/worlds/main/New World/level.dat
```
