# SkyFactory 4

| Field | Value |
|---|---|
| Folder | `skyfactory-4` |
| Minecraft version | `1.12.2` |
| Pack version | `4.2.4` |
| Launcher | `CurseForge` |
| Main world folder | `worlds/main` |
| Extras folder | `extras` |

## Where to put the world

Put the world save contents under:

```text
packs/skyfactory-4/worlds/main/
```

Best layout:

```text
packs/skyfactory-4/worlds/main/level.dat
packs/skyfactory-4/worlds/main/region/
packs/skyfactory-4/worlds/main/playerdata/
```

Also accepted by the packaging tool:

```text
packs/skyfactory-4/worlds/main/New World/level.dat
```
