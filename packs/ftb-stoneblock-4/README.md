# FTB StoneBlock 4

| Field | Value |
|---|---|
| Folder | `ftb-stoneblock-4` |
| Minecraft version | `1.21.1` |
| Pack version | `1.11.1` |
| Launcher | `CurseForge` |
| Main world folder | `worlds/main` |
| Extras folder | `extras` |

## Where to put the world

Put the world save contents under:

```text
packs/ftb-stoneblock-4/worlds/main/
```

Best layout:

```text
packs/ftb-stoneblock-4/worlds/main/level.dat
packs/ftb-stoneblock-4/worlds/main/region/
packs/ftb-stoneblock-4/worlds/main/playerdata/
```

Also accepted by the packaging tool:

```text
packs/ftb-stoneblock-4/worlds/main/New World/level.dat
```
