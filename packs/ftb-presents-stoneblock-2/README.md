# FTB Presents Stoneblock 2

| Field | Value |
|---|---|
| Folder | `ftb-presents-stoneblock-2` |
| Minecraft version | `1.12.2` |
| Pack version | `1.16.1` |
| Launcher | `CurseForge` |
| Main world folder | `worlds/main` |
| Extras folder | `extras` |

## Where to put the world

Put the world save contents under:

```text
packs/ftb-presents-stoneblock-2/worlds/main/
```

Best layout:

```text
packs/ftb-presents-stoneblock-2/worlds/main/level.dat
packs/ftb-presents-stoneblock-2/worlds/main/region/
packs/ftb-presents-stoneblock-2/worlds/main/playerdata/
```

Also accepted by the packaging tool:

```text
packs/ftb-presents-stoneblock-2/worlds/main/New World/level.dat
```
