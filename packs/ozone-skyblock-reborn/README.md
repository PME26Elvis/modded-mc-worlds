# Ozone Skyblock Reborn

| Field | Value |
|---|---|
| Folder | `ozone-skyblock-reborn` |
| Minecraft version | `1.20.1` |
| Pack version | `1.19.1` |
| Launcher | `CurseForge` |
| Main world folder | `worlds/main` |
| Extras folder | `extras` |

## Where to put the world

Put the world save contents under:

```text
packs/ozone-skyblock-reborn/worlds/main/
```

Best layout:

```text
packs/ozone-skyblock-reborn/worlds/main/level.dat
packs/ozone-skyblock-reborn/worlds/main/region/
packs/ozone-skyblock-reborn/worlds/main/playerdata/
```

Also accepted by the packaging tool:

```text
packs/ozone-skyblock-reborn/worlds/main/New World/level.dat
```
